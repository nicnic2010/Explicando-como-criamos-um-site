Como criar um site do zero

Aprenda passo a passo como criar, programar, organizar e publicar um site usando GitHub, HTML, CSS e JavaScript.

ANTES DE COMEÇAR

🧠 O que será utilizado?

Para criar o site, cada ferramenta terá uma função. É importante entender para que serve cada uma.

🌐

GitHub

É onde os arquivos do projeto podem ser guardados e publicados na internet.

🧱

HTML

É utilizado para criar a estrutura e o conteúdo da página.

🎨

CSS

É utilizado para alterar cores, tamanhos, fundos e a aparência do site.

⚙️

JavaScript

É utilizado para criar interatividade, botões, respostas e quizzes.

🎥

PASSO 1

📁 Como criar o repositório

O repositório funciona como a pasta principal onde todos os arquivos do site ficarão.

1. Entrar no GitHub

Abra o navegador do celular ou computador e entre na sua conta do GitHub.

2. Criar um novo repositório

Na página do GitHub, procure o botão ou símbolo:

+ ↓ New repository

Em algumas telas, você também pode encontrar um botão chamado New.

3. Escolher o nome

Procure o campo chamado:

Repository name

Nesse campo, escolha o nome do seu projeto. 

meu-primeiro-site

4. Criar o repositório

Depois de escolher o nome, desça a página e procure o botão:

Create repository

Ao clicar nele, a pasta principal do projeto será criada.

PASSO 2

📄 Como criar os arquivos

O site será separado em arquivos diferentes. Cada arquivo possui uma função.

📁 meu-primeiro-site ├── 📄 index.html ├── 🎨 style.css └── ⚙️ script.js

1. Onde clicar

Dentro do seu repositório, procure:

Add file ↓ Create new file

2. Criar o arquivo HTML

No campo onde aparece o nome do arquivo, escreva exatamente: 

index.html

Abaixo do nome existe uma área grande. É nessa área que você escreve o código HTML.

3. Salvar o arquivo

Depois de escrever, procure o botão:

Commit changes

Esse botão salva o código dentro do GitHub.

4. Criar os outros arquivos

Repita o mesmo processo e crie: 

style.css
script.js

Cada nome deve ser escrito exatamente dessa forma.

PASSO 3

🧱 HTML explicado passo a passo

Todo o código HTML deve ser escrito dentro do arquivo chamado index.html.

1. Informar o tipo de documento

<!DOCTYPE html>

Essa linha informa ao navegador que o documento utiliza HTML5.

2. Criar a tag principal

<html lang="pt-BR">

</html>

Todo o site fica dentro dessa tag.

O lang="pt-BR" informa que o conteúdo está em português do Brasil.

3. Criar o head

<head>

</head>

Dentro do head ficam informações importantes para o navegador.

4. Permitir caracteres especiais

<meta charset="UTF-8">

Essa linha permite que caracteres como ç, ã, é e ô apareçam corretamente.

5. Fazer o site se adaptar ao celular

<meta name="viewport"
content="width=device-width,
initial-scale=1.0">

Essa configuração ajuda o site a funcionar melhor em telas de diferentes tamanhos.

6. Escolher o título da página

<title>
Meu site
</title>

O texto dentro de title aparece na aba do navegador.

7. Conectar o CSS

Ainda dentro do head, escreva: 

<link
rel="stylesheet"
href="style.css">

link cria uma ligação.

rel="stylesheet" informa que o arquivo conectado é CSS.

href="style.css" informa o nome do arquivo que será procurado.

8. Criar o body

<body>

</body>

Tudo que aparece visualmente no site deve ser colocado dentro do body.

9. Criar títulos

<h1>Título principal</h1>

<h2>Título secundário</h2>

h1 é normalmente utilizado para o título principal.

h2 pode ser utilizado para títulos de seções.

10. Criar parágrafos

<p>
Este é um texto.
</p>

A tag p cria um parágrafo.

11. Criar seções

<section>

    Conteúdo

</section>

A tag section organiza o site em partes.

12. Criar grupos

<div>

    Conteúdo

</div>

A div é utilizada para agrupar elementos.

PASSO 4

🎨 CSS explicado passo a passo

Todo o código CSS deve ser escrito dentro do arquivo style.css.

1. Onde escrever o CSS?

Dentro do GitHub, crie o arquivo: 

style.css

Depois de escrever esse nome, use a área grande abaixo para colocar todo o código CSS.

2. Entendendo a estrutura do CSS

body {

    background: pink;

}

body é o elemento que será alterado.

{ inicia as configurações.

background é a propriedade utilizada para alterar o fundo.

pink é o valor escolhido.

; termina a instrução.

} fecha as configurações.

3. Alterar a cor do fundo

body {

    background: #fff0fa;

}

background altera o fundo da página.

4. Alterar a cor do texto

body {

    color: #000000;

}

A propriedade color altera a cor do texto.

5. Alterar o tamanho de um título

h1 {

    font-size: 40px;

}

h1 seleciona o título principal.

font-size altera o tamanho.

40px é o tamanho escolhido.

6. Como utilizar uma classe

Primeiro, no HTML: 

<section class="inicio">

Depois, no CSS: 

.inicio {

    background: purple;

}

O nome da classe é inicio.

No CSS, usamos um ponto antes do nome: .inicio.

7. Arredondar cantos

.card {

    border-radius: 20px;

}

border-radius arredonda os cantos.

8. Criar espaço interno

.card {

    padding: 20px;

}

padding cria espaço entre o conteúdo e a borda.

9. Criar espaço externo

.card {

    margin: 20px;

}

margin cria espaço fora do elemento.

10. Organizar elementos lado a lado

.container {

    display: flex;

}

display: flex ajuda a organizar elementos em uma mesma linha.

11. Criar um fundo com várias cores

.inicio {

    background:
        linear-gradient(
            135deg,
            purple,
            pink,
            lightblue
        );

}

linear-gradient cria uma transição entre diferentes cores.

PASSO 5

⚙️ JavaScript explicado passo a passo

O JavaScript é escrito dentro do arquivo script.js.

1. Criar o arquivo

Add file ↓ Create new file ↓ script.js

A área grande abaixo do nome é onde o código JavaScript deve ser escrito.

2. Para que serve?

HTML → cria

CSS → estiliza

JavaScript → cria interatividade

3. Criar um botão no HTML

<button class="meu-botao">

    Clique aqui

</button>

Esse botão possui a classe meu-botao.

4. Encontrar o botão no JavaScript

const botao =
    document.querySelector(
        ".meu-botao"
    );

const cria uma variável.

botao é o nome escolhido.

document representa a página.

querySelector procura um elemento.

.meu-botao procura a classe chamada meu-botao.

5. Detectar um clique

botao.addEventListener(
    "click",
    function () {

    }
);

addEventListener observa uma ação.

"click" significa clique.

function determina o que acontecerá depois do clique.

6. Mostrar uma mensagem

alert(
    "Você clicou!"
);

alert mostra uma mensagem na tela.

7. Conectar JavaScript ao HTML

No final do arquivo index.html, antes de fechar o body, escreva: 

<script
src="script.js">
</script>

src="script.js" informa qual arquivo JavaScript deve ser conectado.

EXEMPLO PRÁTICO

🧠 Como criar um quiz?

Um quiz pode utilizar HTML para mostrar as perguntas e JavaScript para verificar as respostas.

1. Criar as respostas no HTML

<button class="resposta">
HTML
</button>

<button class="resposta">
CSS
</button>

<button class="resposta">
JavaScript
</button>

2. Encontrar todos os botões

3. Criar a função no JavaScript

Agora precisamos criar uma função para verificar qual resposta foi escolhida. A função é escrita dentro do arquivo script.js. 

function verificarResposta(resposta) {

    if (resposta === "HTML") {
        alert("Resposta correta!");
    } else {
        alert("Resposta incorreta. Tente novamente!");
    }

}

O que cada parte significa?

  • function: cria uma função.
  • verificarResposta: é o nome escolhido para a função.
  • resposta: recebe a resposta escolhida pelo usuário.
  • if: verifica se uma condição é verdadeira.
  • alert: mostra uma mensagem na tela.

4. Conectar os botões ao JavaScript

Para que o botão execute uma ação quando for clicado, podemos adicionar o atributo onclick. 

<button onclick="verificarResposta('HTML')">
HTML
</button>

Quando a pessoa clicar no botão, o site enviará a palavra HTML para a função verificarResposta.

5. Conectar o HTML, CSS e JavaScript

Para que os três arquivos funcionem juntos, precisamos conectá-los dentro do arquivo index.html.

Conectando o CSS

Dentro da tag <head>, colocamos: 

<link rel="stylesheet" href="style.css">

Isso faz com que o HTML encontre o arquivo CSS responsável pelas cores, tamanhos, fundos e aparência do site.

Conectando o JavaScript

No final do body, colocamos: 

<script src="script.js"></script>

Assim, o HTML consegue encontrar o JavaScript responsável pelas ações e interações do site.

📱 Parte 5: Criando os arquivos no GitHub

É possível criar e editar um site diretamente pelo celular utilizando o GitHub.

1. Entrar no GitHub

Primeiro, entre no GitHub utilizando sua conta. Na página inicial, procure o botão de criar um novo repositório.

2. Criar um repositório

Clique no botão New ou no símbolo + e escolha New repository.

Escolha um nome para o projeto. Por exemplo:

meu-site

Depois, deixe o repositório como público e clique em Create repository.

📁 Parte 6: Criando cada arquivo

Dentro do repositório, é necessário criar os arquivos utilizados pelo site.

Arquivo 1: index.html

Clique em Add file e depois em Create new file.

No nome do arquivo, escreva exatamente:

index.html

Depois, cole o código HTML e clique em Commit changes.

Arquivo 2: style.css

Repita o processo e crie um arquivo chamado:

style.css

Nesse arquivo devem ser colocados todos os códigos responsáveis pela aparência e pelas cores do site.

Arquivo 3: script.js

Crie mais um arquivo com o nome:

script.js

Nesse arquivo são colocadas as funções e interações do site, como o funcionamento de um quiz.

🎥 Parte 7: Adicionando um vídeo

Para colocar um vídeo no site, primeiro é necessário enviar o arquivo MP4 para o mesmo repositório.

Depois de enviar o vídeo, ele pode ser colocado no HTML utilizando a tag video. 

<video controls>
    <source src="nome-do-video.mp4" type="video/mp4">
</video>

A palavra controls adiciona os botões para iniciar, pausar e controlar o vídeo.

🌐 Parte 8: Publicando o site

Depois de terminar todos os arquivos, o site pode ser publicado gratuitamente utilizando o GitHub Pages.

Passo 1

Entre no repositório do projeto e procure a opção Settings.

Passo 2

Dentro das configurações, procure a seção chamada Pages.

Passo 3

Na opção de publicação, escolha:

Branch: main

Depois, salve as alterações.

Após alguns minutos, o GitHub cria um link público para o site. Esse link pode ser compartilhado e aberto tanto no celular quanto no computador.

🧠 Resumo: como tudo funciona?

📄 HTML: cria o conteúdo do site.

🎨 CSS: deixa o site bonito, organizado e colorido.

⚙️ JavaScript: cria ações e interações.

🎥 MP4: permite adicionar vídeos.

🐙 GitHub: guarda e publica os arquivos do projeto.

✨ Site finalizado!

Criar um site pode parecer difícil no começo, mas cada linguagem possui uma função diferente.

O HTML cria a estrutura, o CSS cria o visual e o JavaScript adiciona interações.

Depois de conectar todos os arquivos e publicar o projeto no GitHub, o site pode ser acessado por outras pessoas através de um link.

🚀 Agora você já conhece o passo a passo para criar um site!
